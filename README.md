## Start here

Read the selected skill's `SKILL.md` before use. Keep its entire directory together, including `references/`, `scripts/`, `assets/`, and `agents/` when present. Installation locations and activation depend on the receiving agent; this repository does not provide an installer or a universal compatibility claim. See the [Agent Skills specification](https://agentskills.io/specification) for the package format.
