# Local inventory — quick guide

## Inspect metadata

Use the local read-only inventory tool to inspect system metadata. Treat unavailable fields as unknown.

- Review the summary.
  - Check operating system and storage fields.
- Record relevant results.

```text
mode: read-only
label: café
```

| Field | Example |
| --- | --- |
| Label | café |
| Separator | `left\|right` |
