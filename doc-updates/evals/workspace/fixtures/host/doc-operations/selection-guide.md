# Selection window guide

Document ID: DOC-DEMO. Local edition: 2. Authoring basis: GUIDE@core.

## Purpose, audience, and boundaries

This synthetic, nonbinding guide helps demo-host maintainers choose a review window. It excludes production changes and has no external client.

## Recommendation and reason

Consider a review window of 30 seconds to allow a small review pause. This is reasoned advice for the synthetic demo, not an observed optimum; longer windows delay follow-up and shorter windows reduce review time.

See [related guidance](related.md) for the unchanged scope boundary.

## Maintenance

Maintainer unassigned; assignment is needed for a planned review cadence. Revisit when the recommendation or its scope changes and communicate revisions through the updates catalog and session.
