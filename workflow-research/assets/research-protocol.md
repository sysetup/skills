# Research protocol template

Copy and fill. Delete unused brackets. Do not leave instructional text in the user-facing deliverable. For a Gate 0 stop, do not fill this template — ship the six questions only. For an executed desk study, lead with §9 findings; omit empty instrument and timeline sections rather than shipping instructional brackets. Protocol and thesis chapter use the full spine.

## Header

- Working title
- Approach / design / worldview (the Approach = … because … line)
- Deliverable type (protocol / completed inquiry / hybrid / literature-review study)
- Audience
- Date and version
- Assumptions block (inferred Gate 0 slots)

## 1. Problem and significance (step 1)

- Problem in one paragraph
- Who is harmed or blocked if the problem stays unsolved
- Deficiencies in current evidence
- Significance by audience

## 2. Literature and theory (step 2)

- Map of clusters
- Theory or sensitizing concepts
- Terms
- PRISMA-adapted counts (or pointer to §6)

## 3. Purpose, questions, hypotheses (steps 3–4)

- Purpose statement (script)
- Questions
- Hypotheses if quantitative or mixed-quant
- Integration question if mixed

## 4. Design (step 5)

- Worldview write (name, core claims, how it shaped methods, stance)
- Named design and why alternatives were rejected
- Procedure diagram in words if mixed or experimental

## 5. Methods (step 6)

- Population / participants / corpus and sampling
- Data sources and instruments (pointer to appendix; drafts from `assets/instruments.md`)
- Procedure
- Analysis plan (tests or coding products matched to each RQ)
- Integration plan if mixed
- Artifact type, objectives, demonstration, evaluation method if DSRM
- Consistency matrix (`assets/consistency-matrix.md`) — paste the filled table here

## 6. Validation and ethics (step 7)

- Validity / trustworthiness threats and controls
- Integration validity if mixed
- Human-subjects status
- Consent, privacy, risk
- Agent disclosure and algorithmic-instrument threats

## 7. Timeline (cronograma)

| Phase (agent step) | Activities | Weeks | Owner | Gate |
| --- | --- | --- | --- | --- |
| 1 Problem | | | | Problem paragraph signed |
| 2 Literature | | | | Count table + gap list |
| 3 Purpose | | | | Scripted sentence |
| 4 Questions / H | | | | RQ/H locked |
| 5 Design | | | | Approach line locked |
| 6 Methods / collection | | | | Instruments piloted or corpus coded |
| 7 Validation | | | | Threat table ticked |
| 8 Writing | | | | Quality checklist ticked |

Adjust week counts to the user's deadline. Do not invent a 24-month thesis calendar when the user asked for a two-week desk study.

## 8. Execution log (if running now)

Maintain across turns. Do not reset.

- Search strings, tools, and retrieval dates
- PRISMA-adapted counts
- Sources collected
- Coding or analysis decisions and changes
- Instrument-bias notes (see `references/writing-ethics.md`)
- What could not be collected

## 9. Findings (step 8, if executed)

Claims only under `references/inference-license.md` for the named design.

- By question
- Joint display if mixed
- Metainference if mixed
- Demonstration and evaluation against objectives if DSRM
- Empty tables if not executed; do not fill them from step-2 literature unless this *is* a literature-review study

## 10. Limitations and next actions

- Design limits
- Residual fieldwork or data requests
- What a reader must not conclude

## 11. Replication package (when executed)

Required when the study produced scripts, coding matrices, or a stored corpus. Write `N/A — protocol only` when no analysis was run. Do not invent hashes.

- Search strings, tools or databases, and retrieval dates
- PRISMA-adapted counts (Identification / Screening / Eligibility / Inclusion)
- Analysis scripts — path, language (Python / R / Bash), how to run; omit if none
- Raw coding matrices — CSV or JSON path; omit if none
- Local source files — path and SHA-256 (`sha256sum`). Hash only files that exist in the workspace
- Web sources not stored locally — URL, retrieval date, and a short quoted excerpt or `not stored`
- Instrument-bias log pointer (see §8 and `references/writing-ethics.md`)
