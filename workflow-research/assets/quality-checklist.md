# Quality checklist

Fail closed. Tick the blocks that apply, then ship. Artifact intensity lives in `SKILL.md` (Output Contract); this file is the gate, not a second list.

## Clarification (every invocation)

- [ ] Topic-only formal research prompts asked only for missing design-critical information within the available channel's schema and batching limits; no invented protocol, matrix, or findings
- [ ] Specified prompts reused supplied answers and declared only permitted nonblocking assumptions
- [ ] Routine error, incident, DNS, or success diagnosis stayed outside the formal-study loop unless a formal study was requested
- [ ] Required answers, consent, access, and approvals remained pending until actually supplied; no approach was invented to avoid asking
- [ ] One-line definitions skipped this skill's loop

A Gate 1 stop checks only this block and asks the necessary questions; dependent study work waits for required answers.

## Design (every executed inquiry)

- [ ] Worldview, approach, and named design are stated and justified from the problem
- [ ] Quantitative studies name experimental or nonexperimental family, then the variant
- [ ] Qualitative studies pick exactly one of the five designs
- [ ] A bounded incident or system selected case study only for a formal-study request whose question and evidence fit that design
- [ ] Mixed studies have a mixing rationale, a core design, an integration question, and a joint display
- [ ] Purpose script matches the approach
- [ ] Every question is answerable by the methods
- [ ] User-locked designs that cannot answer the question are flagged as mismatch; the Creswell-correct design is proposed
- [ ] DSRM studies name artifact type, objectives, demonstration, and a Hevner evaluation method
- [ ] Literature-review studies are not labeled mixed methods unless two strands integrate

## Inference license (every executed inquiry)

Load `references/inference-license.md`. Tick against that table; do not restate it here.

- [ ] Findings claim only what the named design licenses given the evidence actually collected
- [ ] Search, logs, and coding were not used to upgrade the inference model
- [ ] Unrun experimental, survey, correlational, interview, or mixed strands shipped protocol + empty tables (or pending-strand cells); literature stayed in the step-2 gap argument unless the named design is a literature-review study
- [ ] Causal verbs in Findings rest on this study's assignment and measures, not on prior papers' results

## Executed inquiry (formal desk study / hybrid with required inputs)

- [ ] Report leads with licensed answers to the questions, not with an empty protocol. If the design's data did not run, the lead is the pending-fieldwork list and empty tables — not a substitute synthesis
- [ ] Approach line, purpose, RQ, evidence/inference/recommendation split, validity note, sources, execution log, and limitations are present
- [ ] No fabricated participants, quotes, stats, or references
- [ ] Every empirical claim has a source or is marked assumption
- [ ] Residual fieldwork is listed when humans or data were out of reach
- [ ] Compact matrix attached or explicitly omitted because the deliverable is findings-first (not protocol/thesis)

## Protocol / thesis extras (slot 6 is protocol, thesis chapter, or leftover human fieldwork)

- [ ] Consistency matrix is filled; no orphan cells; trace checks ticked
- [ ] Instruments are drafted and item-mapped to matrix rows
- [ ] Analysis plan is matched to each RQ / hypothesis
- [ ] Timeline covers the eight agent steps
- [ ] Ethics statement is present
- [ ] Executed studies with scripts or a stored corpus include `research-protocol.md` §11 or an explicit N/A

## Evidence (literature-heavy or review studies)

- [ ] Literature section argues a gap, not a dump
- [ ] Desk-research corpus and search strings are visible enough to audit
- [ ] Literature-heavy work includes Identification / Screening / Eligibility / Inclusion counts

## Validity and ethics (every executed inquiry)

- [ ] Threats (quant) or trustworthiness tactics (qual) are specific to this design
- [ ] Human-subjects and privacy issues are treated
- [ ] Algorithmic-instrument threats are named or marked N/A with a reason
- [ ] Limitations match the design, not generic humility

## Report

- [ ] Requested formats, destinations, protected content, and other requested products are preserved; working checks add no unrequested fields
- [ ] Findings answer the questions, or the protocol states they are pending
- [ ] Evidence, inference, and recommendation are separated
- [ ] Mixed studies include a joint display and a metainference (or pending-strand cells)
- [ ] DSRM studies separate demonstration from evaluation and do not treat "we built it" as both
- [ ] Language matches the user
