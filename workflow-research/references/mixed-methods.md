# Mixed methods

Mixed methods is not "some numbers and some quotes." It requires both strands, a reason to mix, a named Creswell core design, an integration procedure, and a metainference. Worldview default: pragmatic. Use transformative when mixing serves justice or voice.

## When to use

Use only if one strand cannot answer the question and the second strand adds a specific function:

- triangulation / corroboration
- complementarity (different facets)
- development (one strand builds the other)
- expansion (breadth + depth)
- intervention or transformative embedding

If the second strand is decoration, drop mixed methods.

## Core designs

**Convergent**
- Collect quant and qual in the same window (or treat as concurrent).
- Analyze separately.
- Merge via joint display (side-by-side, statistics-by-theme, data transformation).
- Resolve divergence (possible, plausible, or collect more).
- Priority usually equal. Sample sizes may differ; do not force them equal.

**Explanatory sequential (QUAN → qual)**
- Quant first (survey, experiment, or secondary numbers).
- Use quant results to select the qual sample (follow up outliers, unexpected cells, high/low groups, or key subgroups). Connecting samples is the integration point.
- Qual explains the numbers (typically interviews or focus groups; phenomenology or case study as the nested qualitative design — pick one).
- Qual n is purposeful and small; it is not a second population estimate.
- Integration question form: To what extent do the qualitative findings explain the quantitative results for {construct} in {subgroup}?
- Do not start the qual strand until quant results (or a simulated analysis plan with empty tables, if data are not yet collected) exist to connect from.

**Exploratory sequential (QUAL → quan)**
- Qual first to find constructs, language, or items.
- Build an instrument or typology (the build step is the integration point). Report how themes became items or factors.
- Quant tests or generalizes.
- Do not skip the instrument-build write-up.

## Complex designs

Embed a core design inside an experiment or intervention, a participatory or transformative project, a program evaluation, or a case or longitudinal frame. Draw a simple procedure diagram (boxes for strands, arrows for sequence, equals-sign or table for merge). Still name the core.

## Required writes

1. Definition of mixed methods as used in this study.
2. Rationale for mixing (one function from the list above).
3. Worldview (usually pragmatic or transformative) and theory.
4. Types of quant and qual data and analyses.
5. Named design + diagram in words.
6. Integration method and timing.
7. Priority (equal, quant-dominant, qual-dominant) and why.
8. Validity issues unique to mixing (unequal samples, divergent results, weak integration, connecting-sample bias).
9. Planned metainferences — what you will be able to say only after integration.

## Joint display

Always produce one table that places quant results against qual results on the same constructs or questions. Last column = inference (convergence, complementarity, divergence + how resolved). Empty cells are allowed when a strand has not been run; fill with `pending strand`.

| Construct or RQ | Quantitative result | Qualitative result | Inference |
| --- | --- | --- | --- |
| {construct} | {estimate / n} | {theme / excerpt pointer} | {meta} |

## Agent execution

Claim license: `references/inference-license.md`. Each strand is licensed by its nested design; the metainference is licensed only after both authorizing collections exist (or the joint display marks the missing strand `pending`).

- Desk mixed methods is allowed — e.g. statistical secondary data + qualitative document or interview-transcript analysis the user supplies.
- Do not label a literature review "mixed methods" unless you actually run two analytic strands and integrate them.
- If only one strand can be executed now, deliver that strand plus the protocol, instruments, and connecting rule for the missing strand. Do not invent the missing strand's findings.
- For "first measure, then explain why" prompts, lock explanatory sequential. Do not silently switch to convergent to save a round.
